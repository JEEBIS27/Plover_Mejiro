このプラグインはRustの共通メジロエンジンで変換します。導入後、PloverのConfigure → Pluginsで `mejiro_engine` を有効にしてください。
Windows 64bitではDLL同梱のビルド済みwheelを使います。利用者側のRust/C++開発環境は不要です。[導入法](#導入法installation)・[ビルド・同期・接続方式](docs/rust-engine.md)

# メジロ式速記(Mejiro)v2

メジロ式速記は、Plover用の日本語の速記システムです。

直観的な**子音＋母音＋追加音**の組み合わせで
片手で1音節、両手で2音節を一気に入力でき、

両手の10本指をフル活用した効率的な日本語入力を体験できます。

## レイアウト(Layout)
このシステムは、メジロ式専用キーボード（[Mejiro31](https://github.com/JEEBIS27/Mejiro31)）や、親指シフト用のキーボード、スペースバーが2つあるキーボードで使うことができます。

ただし、[Mejiro31](https://github.com/JEEBIS27/Mejiro31)にはQMK版メジロ式が導入されているので、ユーザー略語等をカスタムしない人はこのPloverプラグインを使う必要がありません。

```
# S T Y I U    U I Y T S *
# S K N A U    U A N K S *
         n      n             
        t k    k t
```
GeminiPRでは以下のようなレイアウトを想定しています。
```
#1 S1 T P H *1    *3 F P L T D
#2 S2 K W R *2    *4 R B G S Z
           #3     #4             
           A O    E U
```
キーボードを使う場合は次のような配列を想定しています。
```
esc q w e r t y u i o p [
tab a s d f g h j k l ; '
     z x c v b n m , . 
        space enter   
```
※ これはあなたのキーボード配置と異なる可能性があります。
異なる場合はPloveメニューの歯車マーク``Configure``から``Machine``タブを開き、キー配置を変更してください。

## 使い方(How to use)

### 基本入力(Basic Input)

#### 母音(Vowels)

| 出力  | 入力  |
| ---- | ---- |
| あ段  | `A`  |
| い段  | `I`  |
| う段  | `U`  |
| え段  | `IA` |
| お段  | `AU` |
| や段  | `YA` |
| ゆ段  | `YU` |
| よ段  | `YAU`|

---
#### 子音(Consonants)

| 出力   | 入力   |
| ----- | ------ |
| あ行   | --- |
| か行   | `K`    |
| さ行   | `S`    |
| た行   | `T`    |
| な行   | `N`    |
| は行   | `TK`   |
| ま行   | `SKN`  |
| ら行   | `ST`   |
| わ行   | `SK`   |
| が行   | `KN`   |
| ざ行   | `NS`   |
| だ行   | `TN`   |
| ば行   | `TKN`  |
| パ行   | `STK`  |
| ファ行 | `STKN` |
| ぁ行   | `STN` |

※ 法則として、Nと同時押しで濁音化しています。

これらの「子音」と「母音」を組み合わせることで五十音を作ることができます。

`K`+`A` = `KA` →「か」

`KN`+`I` = `KNI` →「ぎ」

---
#### 追加音(Extra)

| 出力 |  入力  |
| --- | ----- |
| ん   | `n`  |
| つ   | `t`  |
| く   | `k`  |
| ち   | `nt` |
| き   | `nk` |
| っ   | `tk` |
| ー   | `ntk`|

このキーを組み合わせると漢字のニ音目の音を追加できます。

`TAk-SAn` →「沢山」

`TKAtk-STKYAk` →「八百」

---
#### 二重母音(Double Vowels)

「あ・い・う・え・お・や・ゆ・よ」以外の組み合わせのときは、日本語で高頻度で出現する二重母音を打てるようになっています。

| 入力 | 出力 |
| --- | ---- |
| `Y` | あい |
| `YIA` | えい |
| `IU` | うい |
| `YI` | よう |
| `YIU` | ゆう |
| `IAU` | おう |
| `YIAU` | うう |

`KYI-TYIAU` → 「共通」

`TYIU-IAU` → 「中央」

`SIU-YIA` → 「水泳」

`TY-KNY` → 「大概」

---
#### マイナー二重母音(Minor Double Vowels)

頻度の少ない母音・二重母音は、母音キーだけでなく追加音キーも使って入力します。

| 末尾 | YI | YIA | Y | IU | YIU | IAU | YIAU |
| --- | --- | --- | --- | --- | --- | --- | --- |
| k | うぃ | うぇ | うぁ | — | — | いぇ | うぉ |
| t | ゆい | やい | いい | おい | よい | あう | いぇい |
| nk | うぃん | うぇん | うぁん | — | — | いぇん | うぉん |
| nt | ゆいん | やいん | いいん | おいん | よいん | あうん | いぇいん |
| tk | うぃっ | うぇっ | うぁっ | — | — | いぇっ | うぉっ |
| ntk | うぃー | うぇー | うぁー | — | — | いぇー | うぉー |

`nk` は `k` 側＋「ん」、`nt` は `t` 側＋「ん」、`tk` は `k` 側＋「っ」、`ntk` は `k` 側＋「ー」です。
「—」は例外かなへ追加音を付けるために空けています。
ウァ・ウィ・ウェ・ウォは子音と合成し、クァ・ツォ・ファ・ヴァなどを入力できます。
従来の「あえ・やう・えあ・いぇあ」とその撥音形、および「いいっ・いんぐ」の専用割り当ては廃止しました。必要な音は複数ストロークで入力します。

`TYIAt-SKNU` → 「チャイム」

`An-STKNIA` ＋ `A-` → 「アンフェア」

---
#### 例外かな(Exceptional Kana)

「わ行や段」のような存在しない行段の組み合わせは特定のマイナーかなに変換されます。

| 子音 | U | YA | YU | YAU | IU | YIU |
| --- | --- | --- | --- | --- | --- | --- |
| STKN | ヴ（通常合成） | フャ（通常合成） | フュ（通常合成） | フョ（通常合成） | テュ | ヴュ |
| SK | ゎ | ゐ | いう | ゑ | ウイ（通常合成） | ウウ（通常合成） |
| TN | ヅ（通常合成） | ティ | デュ | ディ | トゥ | ドゥ |

通常合成と記したセル以外が例外定義です。`STKNU` は「ヴ」、`STKNYU` は「フュ」です。
ヴァ・ヴィ・ヴェ・ヴォは、ファ行＋ウァ・ウィ・ウェ・ウォで入力します。
移動先の「ヴイ・フュウ・ヅイ・ヂュウ」は複数ストロークで入力します。「を」は助詞入力を使用します。
`IU`・`YIU` の `t`・`nt` はマイナー母音を優先し、`n`・`tk`・`ntk` は例外かなに追加音を付けます。

`An-TNYIU` → 「アンドゥ」

`STKNYUntk-TYAntk` → 「フューチャー」

---
### 助詞(Particle)

親指だけで入力した時は追加音ではなく助詞が出力されます。

|入力| 左 | 右 |
|---|----|---|
| `t` | に | は  |
| `k` | の | が  |
|`tk` | で | も  |
|`nt` | と | --- |
|`nk` | を | --- |
|`ntk`| へ／か | や  |

基本的に「左+右」の順に出力されます。

#### (1) 基本「左+右」

`nt-t` → 「とは」

`tk-tk` → 「でも」

#### (2) 対角のnと同時で「〜、」

`nt-nt` → 「とは、」

`n-k` → 「が、」

#### (3) 「〜が」→「の〜」

`tk-k` → 「ので」

`t-k` → 「のに」

#### (4) 例外

|入力|出力|
|---|---|
|`k-k`|な／のが（直前の確定した活用から自動選択）|
|`n-`|Space|
|`-n`|Enter|
|`n-n`|Tab|
|`-nt`|。|
|`-nk`|、|
|`n-nt`|？|
|`n-nk`|！|

`k-k` → 「な」

`k-nk` → 「な、」

単独の `k-k` は、動詞の辞書形・否定形・過去形などの後では「のが」に変わります。
`k-nk` も同じ判定を行い、末尾に「、」を付けます。

|直前の入力|続けて `k-k` を入力した結果|
|---|---|
|`n-*`（している）|しているのが|
|`-k*`（します）|しますのが|
|`-n*`（しない）|しないのが|
|`nt-t*`（したい）|したいのが|
|通常のかな入力（例：かんたん）|かんたんな|
|`k-k`（な）|なのが|

通常のかな・ユーザー略語は品詞を推定せず、既定の「な」を使います。
て形・連用形・仮定形など、どちらも自然に接続しない活用の後でも、既定の「な」を維持します。
丁寧形の「しますのが」は入力仕様として対応しますが、一般的な名詞化では「するのが」が標準的です。
活用と助詞の判定表・根拠は [接続判定の説明](docs/particle-na.md) を参照してください。

#### (5) 「へ／か」の自動判定

`ntk-` は、動詞の終止形・ます形・意向形や、一般略語の名詞の後では「か」を選びます。
一般略語のうち「ここ・こちら・ところ」等の場所・方向を表す語の後と、通常のかな入力の後では「へ」を優先します。

|入力|出力|
|---|---|
|`n-*` → `ntk-`|しているか|
|`-k*` → `ntk-`|しますか|
|`ntk-k*` → `ntk-`|しましょうか|
|`K-T` → `ntk-` ／ `Kntk-T`|ことか|
|`K-KAU` → `ntk-` ／ `Kntk-KAU`|ここへ|
|`K-T` → `ntk-k` ／ `Kntk-Tk`|ことへの|
|`N-N` → `ntk-k` ／ `Nntk-Nk`|なにかの|
|`S-NA` → `k-k` ／ `Sk-NAk`|そんなのが|

右手の「は・も・の・読点」も保持します。「の」が続く場合は、名詞・場所の「への」、
不定語の「何かの」、動詞の「しているかの（よう）」を区別します。
て形・連用形・仮定形や、句読点・カーソル操作の後では、既定の「へ」を使います。

「ここか／ここへ」「ものか／ものへ」のように両方が文法的に可能な場合は、上記の優先規則を使います。
別の接続を意図するときは、通常のかな入力で「か」や「へ」を直接入力できます。
「な／のが」と共通の判定表と適用範囲は [接続判定の説明](docs/particle-na.md) にまとめています。

この判定は Plover のメタプラグインを使用します。更新後は Mejiro パッケージを
Plover の実行環境に再インストールして、Plover を再起動してください。
辞書の `.py` ファイルだけを差し替えても、新しいメタプラグインは登録されません。

---
### 取り消し(Undo)

`-U` で直前の入力を取り消します。Ploverの取り消し履歴が空の場合は、Backspaceを2回送って直前の2文字を削除します。

### 繰り返し(Repeater)

`#`を押すと、全体の出力がもう一度繰り返されます。

`TKAn-Tntk` →「ハンター」

`#TKAn-Tntk` →「ハンターハンター」

`#`の単体でも使えます

`#` → 直前の出力

---
### マクロ(Macro)

左親指の追加音 `n/t/k/nt/nk/tk/ntk` をマクロ名として、出力文字列を記録・再生できます。

| 入力 | 役割 |
| --- | --- |
| `#n-*` (例) | マクロ `n` の記録開始。すでに記録中なら停止。|
| `#-*` | 直近に開始した記録中マクロを1つ停止。|
| `#n` (例) | マクロ `n` の再生。|

記録内容は「実際に出力された文字列」です。
同じマクロで再度 `#n-*` を開始すると、そのマクロ内容は上書きされます。

---
### 略語(Abbreviations)

`*`は一部の特別な入力や略語のために使います。

| 種類 | 役割 | 登録 |
| ------- | --- | ---- |
| ユーザー | 固有名詞や挨拶など | 必要 |
| 動詞 | 動詞(活用も指定) | 任意 |
| 助動詞 | 助動詞(活用も指定) | 不要 |
| 一般 | 抽象名詞や形式名詞 | 不要 |

---
#### ユーザー略語(Users Abbreviations)
ユーザー略語は、固有名詞や挨拶など、特定の語を簡単に入力するために使います。
デフォルトでは何も登録されていません。

定義の仕方は二種類あり、ひとつは`Mejiro/engine.py`の`USERS_MAP`に登録するもので、タイピングゲームでも共通Rustエンジンで変換されます。旧`abbreviations.py`の登録はここへ移してください。

```
<Mejiro/engine.py>
(一例)
USERS_MAP = { # ユーザー略語の定義
  "A-SKNIA": "あめりか",
  "KNUntk-KNU": "ぐーぐる",
  ...
}
```

`In-STKNAU*` → 「インフォメーション」

もう一つは、Ploverのユーザー辞書機能を使う方法で、`mejiro_users.json`に直接登録します。

```
<mejiro_users.json>
(一例)
{
  "AU-S": "おはようございます。",
  "YAU-S": "よろしくおねがいいたします。",
  ...
}
```

定義どおりに出力されるので、タイピングモードでもローマ字やJISかなには変換されません。

---
#### 動詞略語(Verb Abbreviations)
動詞略語は、動詞を入力するために使います。

`TA-STA*` → 「働く」

`KI-TU*` → 「気が付く」

`*` → 「する」

`K-*` → 「くる」

動詞の登録は`abbreviations.py`の`VERB_〇〇_MAP`で行います。

```
<abbreviations.py>
(一例)
VERB_GODAN_MAP = { # ストローク: [語幹, 行]
    "A-STU": ["ある", 'k'],# 歩く
    "TA-TNA": ["いただ", 'k'],# 頂く (例外)
    "I-TNA": ["いだ", 'k'],# 抱く
    "U-KNAU": ["うご", 'k'],# 動く
    ...
}
VERB_KAMI_MAP = { # ストローク: [語幹, 行]
    "SI-SNI": ["しん", 'z'],# 信じる
    "KA-SNI": ["かん", 'z'],# 感じる
    ...
}
VERB_SIMO_MAP = { # ストローク: [語幹, 行]
    "TN-KIA": ["つづ", 'k'],# つづける
    "TN-": ["", 'd'],# 出る
    ...
}
```

登録していない動詞を入力したい場合は、一定の規則により機械的に動詞を生成することができます。

その際は、「左のかな+右の活用部分」という形で動詞が作られ、活用の種類は右の音によって決定されます。

|右の音|活用の種類|
|---|---|
| い段 | 上一段活用|
| え段 | 下一段活用|
| その他 | 五段活用|

`KAn-KNA` `-SKNI` → 「鑑みる」

`KAn-` `KNA-SKNI*` → 「鑑みる」

`TA-SKNIA*` → 「ためる」

`TA-SKNA*` → 「たまる」

ただし、上一段、下一段として存在しない動詞の場合はラ行の五段活用になります。

`TKA-SI*` → 「走る」

`TA-STKI*` → 「タピる」

わ行い段・え段を使うことで明示的に活用を指定することもできます。

`KA-IA*` → 「帰る」

`KA-SKIA*` → 「変える」

また、右側に何も入力せずに`*`だけを押した場合は、「～する」という動詞を作ります。

`TY-*` → 「対する」

`TNIAU-*` → 「どうする」

すべての動詞は、追加音のキーで活用形を指定できます。

|入力|左|右|
|---|---|---|
| `n` |ている|ない|
| `t` |させる|た|
| `k` |られる|ます|
| `nt`|---|なかった|
| `nk`|てしまう|ません|
| `tk`|れる（ら抜き）|ました|
|`ntk`|---|て|

`KA-KNAn*` → 「考えない」

`A-STUt*` → 「歩いた」

左が`nt`、`ntk`のときは特別な活用になります。

|入力|出力|
|---|---|
|`nt-`|やすい|
|`nt-k`|やすく|
|`nt-n`|にくい|
|`nt-nk`|にくく|
|`nt-t`|たい|
|`nt-tk`|たく|
|`nt-nt`|てほしい|
|`nt-ntk`|てください|
|`ntk-`|連用形|
|`ntk-n`|ず|
|`ntk-t`|ば|
|`ntk-k`|ましょう|
|`ntk-nt`|なければ|
|`ntk-nk`|なく|
|`ntk-tk`|ながら|
|`ntk-ntk`|よう（意向形）|

`SIntk-SNInt*` → 「信じなければ」

`KNAtk-TKNAntk*` → 「頑張ってください」

---
#### 助動詞略語(Auxiliary Verb Abbreviations)
助動詞略語は、一部の助動詞を入力するために使います。

※ 現状は「です」だけに対応しています。

|入力|出力|
|---|---|
|`-TN`|です|

`-TN` → 「です」

「左のかな+助動詞」という形でも入力できます。

`SIAU-TN` → 「そうです」

助動詞略語は、右手の追加音のキーで活用形を指定できます。

|入力|出力|
|---|---|
|`n`|ですね|
|`t`|でした|
|`k`|でしょう|
|`nt`|です。|
|`nk`|ですが、|
|`tk`|ですか？|
|`ntk`|でして、|

`SIAU-TNntk` → 「そうでして」

`TNIAU-TNk` → 「どうでしょう」

`NAn-TNtk` → 「なんですか？」

---
#### 一般略語(Abstract Abbreviations)
一般略語は、こそあど言葉や抽象名詞、形式名詞など、特定の語を簡単に入力するために使います。

こそあど言葉は`*`なしで入力します。

|入力 |`-KAU`|`-TI` |`-STA`|`-STIA`|`-NA`|
|-----|------|------|------|-------|------|
|`-`  |あそこ|あっち|あちら|あれ   |あんな|
|`K-` |ここ  |こっち|こちら|これ   |こんな|
|`S-` |そこ  |そっち|そちら|それ   |そんな|
|`TN-`|どこ  |どっち|どちら|どれ   |どんな|

`-KAU` → 「あそこ」

`K-TI` → 「こっち」

`S-STA` → 「そちら」

`TN-STIA` → 「どれ」

`S-NA` → 「そんな」

以下の表の一般略語も`*`なしで入力します。

|入力|出力|
|---|---|
|`ST-`|から|
|`K-N`|かん|
|`K-SN`|かんじ|
|`K-T`|こと|
|`KN-T`|ごと|
|`K-TKN`|ことば|
|`K-ST`|ころ|
|`T-TN`|ただ|
|`TN-K`|だけ|
|`TN-ST`|だから|
|`T-KI`|てき|

### タイピングモード(Typing Mode)

`#-t` はIMEをONにします。`#-k` は利用可能な別システムへ切り替えてからIMEをOFFにします。
PloverではPhonetixが登録されている場合だけ切り替え、未導入ならIME OFFだけを行います。
切り替え先は辞書の `MEJIRO_ALTERNATE:Phonetix` の引数で指定できます。切り替えに失敗した場合もIME OFFへ進みます。
F13/F14は送信せず、Ploverの `MEJIRO_IME` プラグインでOSの専用キーに変換します。
QMKの `KC_LNG1`／`KC_LNG2` と揃え、LinuxはHangul／Hangul_Hanja、WindowsはVK_HANGUL（`0x15`）／VK_HANJA（`0x19`）、macOSはJISかな／英数キーを使います。
Linuxでは使用するIMEがこれらをON／OFFとして扱う設定が必要です。
更新後はMejiroパッケージを再インストールしてPloverを再起動してください。

初期状態はローマ字入力のタイピングモードです。IMEをONにして使うことで、Linux・macOSでも未確定文字として変換できます。
Ploverの履歴はかなで保持し、送信時だけローマ字へ変換します。たとえば「では」は `deha` と送信しますが、undoではかな2文字分を削除します。末尾の促音は保留し、次の出力履歴の先頭に含めます。IMEで漢字への変換・確定や外部の編集を行った後の文字数は取得できないため、このundoは未確定のかな入力を前提とします。
タイピングモードでは、ローマ字入力あるいはJISかな入力で出力できます。
出力形式の設定は、Mejiro/engine.pyの``typing_mode``変数で行います。
```
<Mejiro/engine.py>
typing_mode = 0  # 0: ローマ字入力, 1: JISかな入力
```

タイピングモードは、`#-n`でonとoffを切り替えられます。

## 片手モード

記号を含めた左側の全押し `#STKNYIAUntk-` で左手モード、右側の全押し `-STKNYIAUntk*` で右手モードに移行します。
両側の全押しで両手モードへ戻ります。反対側を含む通常入力も、その打鍵から両手入力として扱い、以降両手モードに戻ります。片手略語の記号キーは、左手モードでは左の `#`、右手モードでは右の `*` を使います。

基本のかな・追加音・母音表は両手版と共通です。片手入力では子音単体の五段動詞生成は従来どおりです。い段・え段は記号キーなしでは通常のかな入力（`KI`＝き、`KIA`＝け）になり、記号キー付きの場合だけ一般略語・登録動詞の判定後に上一段・下一段の動詞を生成します。
以下の `*` はその手の記号キーを表します（左手の `K*` は `#K-`、右手は `-K*`）。`*` 付きは一般略語を優先し、`K*`＝この、`S*`＝その、`ST*`＝から、`KAU*`＝こと、`TAU*`＝ところ、`TKA*`＝はなし。専用動詞は `*`＝する、`KU*`＝くる、`TN*`＝「です」です。
残りの略語枠には共通エンジンの片手登録動詞を使います。右手モードでは同じ入力を右側で行います。

| 親指 | 単独 | 一般略語＋`*` | 動詞活用 |
| --- | --- | --- | --- |
| `n` | Space | 、 | ない |
| `t` | 、 | に | た |
| `k` | 。 | の | ます |
| `tk` | ・ | で | ました |
| `nt` | ？ | と | なかった |
| `nk` | を | を | ません |
| `ntk` | Enter | は | て |

この機能は片手モード対応の共通エンジンを含むプラグインで利用できます。

## 導入法(Installation)

### メジロ式をインストールする(Installing Mejiro)

Windows 64bit用のビルド済みwheelにはRustエンジンのDLLが含まれています。RustやVisual Studio Build Toolsの導入は不要です。

1. [Releases](https://github.com/JEEBIS27/Plover_Mejiro/releases)のAssetsから、末尾が `-py3-none-win_amd64.whl` のファイルをダウンロードします。
2. Ploverを終了し、Ploverのインストール先フォルダーでPowerShellを開きます。ショートカットの「ファイルの場所を開く」から探せます。
3. 次のコマンドでインストールします。wheelのパスは実際にダウンロードしたファイルの絶対パスに置き換えてください。

```powershell
.\plover_console.exe -s plover_plugins install --upgrade "C:\Users\ユーザー名\Downloads\mejiro-2.8.1-py3-none-win_amd64.whl"
```

4. `Successfully installed` と表示されたら、Ploverを起動します。更新時も新しいwheelで同じ手順を行います。

wheelがまだReleasesにない場合は、配布者が下記の[ビルド・配布手順](docs/rust-engine.md#wheelのビルド配布)で作成したものを受け取ってください。Windows 32bitやARM64のPloverには、このwheelは使えません。

Plugin Managerの「GIT」はソースからビルドするため、一般利用者向けには使いません。macOS/Linuxでソースから導入する場合の開発環境は[こちら](docs/rust-engine.md)を参照してください。

Ploverのコマンドによる導入方法は[公式Wiki](https://plover.wiki/index.php/Invoke_Plover_from_the_Command_Line)も参照できます。

---
### メジロ式を起動する(Activating Mejiro)

このプラグインをインストールしたあと、Ploverを再起動し、Ploverメニューの歯車マーク``Configure``から``Plugins``タブを開いて `mejiro_engine` を有効にします。続いて``System``タブから``Mejiro``システムを選択して起動します。
