# 「な／のが」「へ／か」の接続判定

## 文法と入力仕様

「簡単な」の「な」は、学校文法では形容動詞の連体形の活用語尾に当たる。
動詞の後に同じ「な」は付かない。「するな」のような禁止・終助詞の「な」は今回の対象外。
一方、「しているのが」の「の」は節を名詞化し、「が」がその名詞句に付く。

名詞化する「の」は、動詞やイ形容詞の連体形に接続できる。
ナ形容詞の語幹なら「静かなのが」のように「な」が必要になる。
通常のかな入力からは品詞が確定しないので、「い」「る」などの文字列の末尾による推測は行わない。
「きれい」「きらい」がイ形容詞とは限らず、かな入力した「かえる」も動詞とは限らないためである。

二択で自然な接続が確定するときだけ「のが」に切り替え、それ以外は既定の「な」を出力する。
この既定動作は、直前と「な」の接続が文法的に正しいと判断したことを意味しない。
先行文字列を書き換えたり、足りない述語を補ったりする処理は行わない。

一般略語は辞書で確定する語を分類する。「そんな・こんな」等は連体詞として扱い、
後ろの `k-k` で「そんなのが・こんなのが」とする。
複合略語でも、左側だけの「こんな」等は同じ扱いにする。
一方、左側だけの「この・その・こういう」等では名詞がまだ出ていないので、名詞として扱わない。
なお `-NA` は標準のコマンド辞書では「「」に上書きされるため、一般略語の「あんな」としては判定しない。

丁寧形は別扱いにする。一般的な名詞修飾・名詞化では普通形を用いるため、
「しますのが」は「するのが」ほど標準的ではない。
ただし、要求された入力仕様として「ます・ません・ました」の後は「のが」を選び、
元の丁寧形は変更しない。「です・でした」も同じ入力方針にする。

## 動詞・助動詞の判定表

すべての動詞略語と、略語に未登録の機械生成動詞に共通の判定を使う。
五段・上一段・下一段・サ変・カ変の別ではなく、最終的な活用形で判断する。
左側の `n/t/k/nk` が補助動詞・使役・受身を作っていても、右側の最終形を見る。

|左側の活用キー|右側の活用キー|出力末尾|続く `k-k`|
|---|---|---|---|
|なし・`n/t/k/nk`|なし|辞書形：する・している・させる・られる・てしまう|のが|
|同上|`n`|ない|のが|
|同上|`t`|た／だ|のが|
|同上|`nt`|なかった|のが|
|同上|`k/nk/tk`|ます・ません・ました|のが（丁寧形の入力方針）|
|同上|`ntk`|て／で|な（接続は保証せず既定動作）|
|`nt`|なし・`n/t/nt`|やすい・にくい・たい・てほしい|のが|
|`nt`|`k/nk/tk`|やすく・にくく・たく|な（同上）|
|`nt`|`ntk`|てください|な（依頼表現。名詞化の対象外）|
|`tk`|なし・`n/t/nt`|可能の辞書形・ない・た・なかった|のが|
|`tk`|`k/nk/tk`|可能のます・ません・ました|のが（丁寧形の入力方針）|
|`tk`|`ntk`|可能のて／で|な（既定動作）|
|`ntk`|なし|連用形|な（名詞的用法もあるが、名詞化接続を確定しない）|
|`ntk`|`n/nk`|ず・なく|な（接続は保証せず既定動作）|
|`ntk`|`t/nt`|ば・なければ|な（同上）|
|`ntk`|`tk`|ながら|な（同上）|
|`ntk`|`k/ntk`|ましょう・意向形|な（同上）|
|ですの略語|なし・`t`|です・でした|のが（丁寧形の入力方針）|
|ですの略語|`n/k`|ですね・でしょう|な（終助詞・推量であり自動名詞化しない）|
|ですの略語|`nt/nk/tk/ntk`|です。・ですが、・ですか?・でして、|な（句読点・質問・接続の後なので既定動作）|

一般略語／左かなに付く断定の「である」「だった」は名詞化できるため「のが」を選ぶ。
「だ」の後は、どちらかを追加するだけでは「なのが」にできないため既定動作にする。

## 助詞の判定表

格助詞・係助詞・接続助詞は、後続する述語や名詞を必要とする。
たとえば「に」の後では「にな」「にのが」のどちらも、今回の連体修飾・名詞化として自然にならない。
「との」「への」の「の」も、名詞化の「の」と一律に同一視できない。
したがって、「助詞なら全部のが」といった補正はしない。

|メジロ式で生成する助詞・組み合わせ|続く `k-k`|理由|
|---|---|---|
|な|のが|な＋名詞化の「の」＋が → なのが|
|に・の・で・と・を・へ|な（既定動作）|格助詞の後には通常、名詞や述語が必要|
|は・が・も・や|な（既定動作）|主題・格・取り立て・並列の後で、名詞化可能な述語は未確定|
|には・にも・では・でも・とは・とも・へは・へも・をは・をも|な（既定動作）|重なった助詞も述語等を要求。「をは」自体の出力仕様は本変更の対象外|
|のは・のも・のを|な（既定動作）|名詞化済みでも、その後ろにさらに名詞化の「の」は付けない|
|のに・ので|な（既定動作）|接続助詞としては後続節が必要。格助詞としても述語は未確定|
|との・への|な（既定動作）|名詞を修飾する連語であり、後続名詞は未確定|
|上記＋読点、句点、?、!|な（既定動作）|句読点で判定を区切る。「な、」の次にも「のが」を持ち越さない|
|Space・Enter・Tab、カーソル移動等|な（既定動作）|接続する直前の語を保証できない|

## `ntk-` の「へ／か」

「へ」は名詞句に付き、移動の方向や到達先・相手等を表す。
「か」は述語に付いて疑問を作り、「何か・どれか」のような不定表現や「AかB」の選択にも使う。
したがって、品詞だけでなく、活用形と後続助詞を合わせて判断する必要がある。

ただし「ここか／ここへ」「ものか／ものへ」はどちらも文法的に可能であり、
前の語だけから話し手の意図を一意には決められない。
以下は文法上の接続条件に基づく入力の優先規則で、文全体の意味を解析した結果ではない。
別の接続を意図するときは通常のかな入力の「か」（`KA-`）・「へ」（`TKIA-`）を使える。

### 単独の `ntk-` と `k-k` の共通判定表

|直前に確定している出力|`k-k`|`ntk-`|判断|
|---|---|---|---|
|動詞の辞書形・ない・た・なかった、やすい・にくい・たい・てほしい|のが|か|名詞化でき、疑問も作れる述語|
|ます・ません・ました、です・でした|のが|か|前者は指定された入力方針、後者は丁寧形の疑問|
|ましょう・意向形、でしょう|な（既定）|か|「しましょうか・しようか・でしょうか」。名詞化の接続とは別|
|て／で・連用形・ず・なく・ば・なければ・ながら・てください|な（既定）|へ（既定）|二択を追加するだけでは通常の名詞化・疑問を作れない|
|一般略語の名詞：こと・もの・ひと・とき・ころ・かんじ等|な（既定）|か|名詞述語の疑問・選択を優先する|
|一般略語の場所・方向：あそこ／ここ／そこ／どこ、あっち／こっち／そっち／どっち、あちら／こちら／そちら／どちら、ところ／とこ|な（既定）|へ|場所・方向への移動を優先する|
|一般略語のなに・なん・どれ|な（既定）|か|不定語の「何か・何か（なんか）・どれか」を優先する|
|一般略語のあんな・こんな・そんな・どんな、助詞として出力したな|のが|へ（既定）|名詞化には「の」を付けられる。「なか」「なへ」は適合を保証しない|
|複合略語の左側だけ：あの・この・その・との・どの・なんの・いう・こういう等|な（既定）|へ（既定）|連体修飾語の後に名詞がまだ必要|
|の・と・も・から・だから・だけ|な（既定）|か|「のか」「とか」「もか」「からか」「だからか」「だけか」の接続を優先|
|上記以外の助詞・複合助詞|な（既定）|へ（既定）|後続の述語等が未確定。古い動詞の活用を持ち越さない|
|一般略語のただ、通常のかな、ユーザー略語・ユーザー辞書の出力|な（既定）|へ（既定）|品詞・用法を確定せず、文字列末尾による推測もしない|
|句読点・改行・Space・Tab・カーソル操作の後|な（既定）|へ（既定）|接続判定を区切る|

一般略語の名詞でも、「ことだ」の後に「か」を追加した「ことだか」は作らない。
名詞述語・ナ形容詞の普通形の疑問では「だ」を除く必要があるが、この処理は先行出力を変更しない。
「ことであるか」「ことだったか」は活用済みの述語として「か」を選べる。

### `ntk-` と右手の助詞を組み合わせる場合

|入力|「へ」を選ぶ文脈|「か」を選ぶ文脈|
|---|---|---|
|`ntk-`|へ|か|
|`ntk-n`|へ、|か、|
|`ntk-t` / `ntk-nt`|へは / へは、|かは / かは、|
|`ntk-tk` / `ntk-ntk`|へも / へも、|かも / かも、|
|`ntk-k` / `ntk-nk`|への / への、|かの / かの、|

「は・も」が続く場合も同じ語の種類・活用から選ぶ。
「するかは分からない」「するかもしれない」等の後続表現を入力できる。
ただし「しますかも」のように丁寧形との組み合わせが標準的でないものもあり、
この処理では普通形への書き換えや後続語の補完は行わない。

「の」が続く場合は、次のように別の優先規則を使う。

- 名詞・場所・品詞不明の入力は「への」を優先する。「ことへの理解」「ここへの道」「ひとへの手紙」等。
- 不定語を作れる「なに・なん・どれ」は「かの」を選ぶ。「何かの間違い」「どれかの本」等。
- 名詞化可能な動詞等の述語は「かの」を選び、「しているかのよう」のような続きに使える。
- 意向形・ましょう・でしょう等や、その他の助詞・未完成な修飾語の後では既定の「への」を維持する。
  この場合も接続を保証する意味ではなく、二択だけで自然に直せないための既定動作である。

読点を出した後の判定は持ち越さない。「何か、」の次の `ntk-` は既定の「へ」になる。
「何かの」は「何＋か＋の」の接続であり、一般の「こと＋への」と一律に置換しない。

## Plover への反映

以前は、すべての入力で呼ばれる `joshi()` がグローバル変数 `prev_joshi` を更新し、
「前の助詞が『な』だったか」だけで交互に切り替えていた。
辞書の参照は実際の出力とは限らず、動詞活用も反映されなかった。

現在の `joshi()` は常に同じ助詞を返す。確定した出力にだけ文法情報を付け、
Plover のメタプラグイン `{:mejiro:…}` が書式履歴の action に保存する。
単独の `k-k` と `k-nk`、`ntk-` と右手助詞の組み合わせは、実際に出力する時点でその履歴を見る。
これにより undo 後の文脈、同時に処理される複数の translation、
出力を伴わない書式指定にも対応する。未知の文字やキー操作を越えて過去の動詞を参照しない。
新しい文法用の「前回の出力」グローバル変数は持たない。

タイピングモードでも判定は日本語の活用情報で行い、解決した助詞を最後にローマ字／JISかなに変換する。
マクロには解決済みの実出力を記録する。記録・再生した文字列から品詞を推測する処理は行わない。
繰り返しの `#-` も解決済みの文字列を使うため、「な」の繰り返しが再判定で「のが」に変わることはない。
同一ストロークの「左かな＋助詞」や一般略語＋助詞では、その語の接続情報を使い、前の語の文脈を参照しない。
一般略語＋助詞と、一般略語の次に単独で助詞を打つ場合は、共通の `joshi()` と接続判定を使う。
一般略語をすべて「か」にする文字列置換は行わない。

メタプラグインのエントリーポイントを追加したため、Plover に登録されている Mejiro パッケージの再インストールと再起動が必要。
`Mejiro.formatting.GrammaticalAction` は Plover の `_Action` を拡張しており、Plover の書式処理 API が変わる場合は再検証する。
